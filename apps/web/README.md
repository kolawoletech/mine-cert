# MineCert web

The Next.js App Router application provides the first responsive MineCert
workspace dashboard shell.

Run it from the repository root:

```sh
pnpm --filter @minecert/web dev
```

Open `http://localhost:3000`. Dashboard records and activity are illustrative;
the web application is not yet connected to the API. Authentication, search,
notifications, and equipment workflows are planned.

Use the root [README](../../README.md) for the full local development setup.
